# Site Monitor

Сервис мониторинга сайта: авторизуется через браузер, собирает данные, сохраняет их в базу и присылает новые записи в Telegram.

## Пример работы

![Уведомления в Telegram](screenshot.png)

## Возможности

- **Браузерная автоматизация** на Playwright (Chromium, headless)
- **Авторизация** на сайте и сохранение сессии (cookies) между запусками
- **Восстановление после сбоев**: повторные попытки, сброс сессии и повторный вход
- **SQLite**: хранение данных и определение только новых записей
- **Telegram Bot API**: уведомления о новых записях и об ошибках
- Логирование в файл `monitor.log`

## Стек

Python 3, Playwright, SQLite, Telegram Bot API, requests

## Установка

```bash
pip install -r requirements.txt
python -m playwright install chromium
```

## Запуск

Токен бота и chat id передаются через переменные окружения (в коде их нет):

```bash
# Windows
set TG_TOKEN=ваш_токен
set TG_CHAT_ID=ваш_chat_id

# Linux / macOS
export TG_TOKEN=ваш_токен
export TG_CHAT_ID=ваш_chat_id
```

```bash
python monitor.py --once   # один проход
python monitor.py          # постоянный мониторинг (по умолчанию каждые 300 с)
```

Дополнительно: `INTERVAL` — интервал проверки в секундах, `SITE_LOGIN` / `SITE_PASSWORD` — данные для входа.

## Как работает

1. Открывает сайт; если сессия не активна — выполняет вход и сохраняет сессию в `session.json`
2. Проходит по страницам и собирает записи
3. Сохраняет их в `data.db`; новые записи определяются по хэшу содержимого
4. Отправляет новые записи в Telegram (не больше 5 сообщений за проход, чтобы не спамить)
5. При ошибке делает до 3 попыток с паузой и повторным входом

В качестве примера используется учебный сайт [quotes.toscrape.com](https://quotes.toscrape.com), созданный для практики парсинга.
